# Corrida do Douro (POO – UAL 2026/27)

Projeto prático da cadeira de Programação Orientada a Objetos.

## O Jogo
O jogo consiste numa corrida de barcos Rabelo ao longo do Rio Douro, jogada por turnos num tabuleiro linear:
- **Objetivo:** Chegar primeiro à última casa do percurso.
- **Turnos:** Cada jogador lança o dado / calcula o movimento e avança as respetivas casas.
- **Casas Especiais:** Existem casas neutras, casas com correntes que dão avanço extra e obstáculos (bancos de areia / correntes contrárias) que atrasam o barco.
- **Fim do jogo:** Vence o primeiro barco a cruzar a meta.

## Estrutura
- `src/`: Código Java (tabuleiro, regras e barcos).
- `test/`: Testes unitários das regras.
- `docs/`: Relatório de progresso (`STATUS_OCTOBER.md`).

## Como Correr
1. Abrir a pasta no terminal ou no IDE (IntelliJ / VS Code).
2. Compilar e executar a classe principal a partir da pasta `src/`.
