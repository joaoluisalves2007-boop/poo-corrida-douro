# Passos GitHub (outubro)
1. Um de vocês cria o repositório; Settings > Collaborators: adicionar o colega e o docente.
2. Cada um com a sua conta, na pasta do projeto:
   git init && git add . && git commit -m "Rules, board map and movement prototype"
   git branch -M main && git remote add origin <URL> && git push -u origin main
3. Cada um faz commits próprios (ex.: A revê/ajusta modelo, B revê/ajusta consola e testes) com mensagens reais.
4. Antes de 29/10: git tag oct-checkpoint && git push --tags
5. Moodle: colar URL + tag/hash no relatório (docs/STATUS_OCTOBER.md).
